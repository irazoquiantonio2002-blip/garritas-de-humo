# Garritas de Humo

Landing page de Garritas de Humo, nail artist en Zona Zapopan, Guadalajara. Técnica soft gel, gelish, rubber y press on.

Sitio estático (sin build ni dependencias): abre `index.html` en el navegador, o sírvelo con cualquier servidor estático.

## Estructura

- `index.html` — marcado y SEO
- `css/styles.css` — sistema de diseño (tema oscuro, acentos jade + rosa neón)
- `js/main.js` — animaciones, menú, acordeón, carrusel y formulario a WhatsApp
- `img/` — logo, fotos y videos del portafolio
- `fonts/` — Bricolage Grotesque y Geist, autohospedadas
